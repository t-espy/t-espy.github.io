Selected Projects

Strategy Assayer — Evaluation Infrastructure

An ML evaluation and provenance framework with a parallel experiment engine underneath. Candidates do not ship because a search looked good. They ship if they clear tiered evaluation: walk-forward holdout, randomized control arms, null distributions, multiple-trial correction, blocking promotion gates, and hash-stamped run records (plan hash, code SHA, engine version). The public lean-optimizer-public repository is the orchestration-engine slice: warm worker pools, a persistent harness, and directed search (genetic, Latin Hypercube, Bayesian/Optuna TPE, local grid). QuantConnect LEAN is the evaluation workload.

The engine is why the expensive tests are routine. A 679,140-point parameter space converged in 611 evaluations — 1,112× fewer than exhaustive grid search — in under three minutes against an ~88-hour grid-search extrapolation. The private platform adds the evaluation and promotion pipeline: 13 experiment families, 25,000+ experiment plans, 86,000 walk-forward windows, and 5.2 million evaluation runs. Production promotion is manually gated.

langgraph-factory — Multi-Agent Code Generation with Local LLMs

Agentic pipeline engineering with automated verification loops. A foreman model owns architecture planning and build diagnostics; a coder model owns file generation and targeted fixes. When the build fails, recovery is layered: deterministic mechanical fixes first, then reviewer-guided patches, spin detection, and failure-informed regeneration — without a human in the loop for the retry. A sample run produced a 24-file blog platform in 266 seconds, entirely on local models.

Explicit plans, bounded tool access, test discipline, and human-owned architecture keep the workflow controlled. The pipeline runs on locally hosted LLMs (Docker Model Runner on a DGX Spark) — no API keys, no per-token cloud cost for the generate/fix loop.

agent-coord — Coordination Board for AI Coding Agents

A coordination board for AI coding agents on separate machines. It is not a task runner or a build queue: it answers who is working on what when any worker can die. Claims are leased and heartbeaten; identity comes from the bearer token; the daemon is stateless over Postgres. Agents attach over MCP; humans and scripts drive the same board through a CLI.

Built for the Strategy Assayer fleet and used in production across those boxes. A finding posted as a card survives a context compaction that would otherwise lose it; that is the same session-memory problem the methodology page describes, implemented as infrastructure rather than convention.
