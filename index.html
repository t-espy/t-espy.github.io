Selected Work

LEAN Research-to-Live Platform & lean-optimizer

Private QuantConnect LEAN research-to-live infrastructure platform with a public optimizer-engine subset. The public repository compiles C# strategies once, runs warm Docker containers with persistent .NET harness processes, and searches parameter space using genetic, Latin Hypercube, Bayesian/Optuna TPE, and local-grid stages. The private system adds IBKR data ingestion, WFO/WFAC credibility validation, portfolio construction, prediction bands, parameter-staleness monitoring, live/paper deployment packaging, dashboard approval, and post-trade analytics.

The platform has evaluated seven strategy families across 257 symbols, run 5,563 research test plans and 36,254 walk-forward windows, and maintains more than 2,000 private automated tests. A bounded LLM-guided Research Steward can read results and queue follow-on experiments through restricted interfaces; live trading remains separate and manually approved.
