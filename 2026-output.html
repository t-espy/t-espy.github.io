2026 Engineering Output

A measured year of source, tests, and engineering documentation

← Back to portfolio

From 1 January through 21 September 2026 I added on the order of 500,000 lines of source across 34 GitHub repositories (5 public, 29 private), at more than 50,000 source insertions per month. Tests and documentation sit on top of that. The numbers come from git insertions, not from a marketing dashboard.

Lines of code are not a measure of software quality or developer productivity. I use them here only as a reproducible measure of the volume and breadth of engineering work produced with my current AI-assisted workflow. The rest of this portfolio provides the quality, architecture, validation, and shipped-system evidence behind the volume.

What the number is

Counts are non-merge git insertions since 1 January 2026, classified by path and extension, on local checkouts of every GitHub repo with a 2026 push. Public snapshots that copy a private tree (ratchetloop-public, lean-optimizer-public) are counted once. Local clones of the same work are dropped.

Insertions count rewrites: a file edited five times contributes five times. That is the honest “produced this year” figure. It is not the same as “500,000 lines sitting in trees today, all still earning their keep.” A few trees also carry vendored or generated bulk; those inflate on-disk size more than they inflate 2026 insertions.

Where the volume sits

Three piles, not thirty-four unrelated hobbies.

  • Evaluation and search. lean-optimizer alone is about half of all GitHub insertions this year (~265k source, ~118k tests, ~52k docs), with a C# strategy layer around it. The public orchestration-engine slice is lean-optimizer-public.
  • Lab and agent tooling. Supervisor, delivery pipeline, and coordination: lab-manager, buildloop, ratchetloop, agent-coord. The public pipeline snapshot is ratchetloop-public.
  • Product slices. Market-intelligence software, job-search automation, Meetup Finder, website and asset factories. Visible output includes leetcode-python (produced through ratchetloop) and langgraph-factory.
